Sobre mim

Olá! Me chamo Leonardo Paes Ribeiro dos Santos, tenho 23 anos e sou acadêmico do 4º período do curso de Bacharelado em Sistemas de Informação no IF Goiano - Campus Ceres. Resido em Ceres e tenho grande interesse pelo ecossistema de desenvolvimento de software e infraestrutura tecnológica.

Escolhi a área de Sistemas de Informação pela oportunidade de solucionar problemas reais por meio da computação, unindo lógica estruturada, bancos de dados e engenharia de software para transformar processos. Considero a programação web essencial para a construção de soluções acessíveis e integradas no cenário atual.

Minha trajetória

Minha formação computacional vem sendo construída por meio de disciplinas práticas focadas em arquitetura de computadores, redes locais, modelagem de banco de dados relacional e lógica de programação. Busco constantemente aplicar os conhecimentos acadêmicos em exercícios reais de versionamento e implementação de sistemas.

O que já sei

  • Estruturação semântica de páginas com HTML5
  • Controle de versão e fluxo de trabalho com Git e GitHub
  • Conceitos de redes de computadores e arquitetura de sistemas
  • Manipulação e consultas estruturadas em bancos de dados relacionais (SQL)

Como aprendo melhor

  1. Estudo os conceitos teóricos e fundamentos da documentação oficial.
  2. Acompanho demonstrações práticas e análise de código em aula.
  3. Desenvolvo projetos práticos e exercícios para fixação do conteúdo.
  4. Depuro erros e realizo testes no navegador com ferramentas de inspeção.

Conceitos fundamentais

Semântica HTML
Prática de utilizar cada elemento HTML de acordo com o seu real significado conceitual e acessibilidade, e não apenas pelo seu aspecto visual padrão.
Versionamento de Código
Sistema de controle que registra o histórico de alterações dos arquivos ao longo do tempo, facilitando colaboração, rastreabilidade e reversão de falhas.
