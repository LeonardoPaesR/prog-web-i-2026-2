Sobre mim

Olá! Me chamo Leonardo Paes Ribeiro dos Santos, tenho 23 anos e sou acadêmico do 4º período do curso de Sistemas de Informação no IF Goiano - Campus Ceres. Resido em Ceres e tenho grande interesse pelo de desenvolvimento de software e aplicativos, sendo uma area que sempre tive interesse em seguir como carreira profissional, este projeto de programação web serviu para o meu aprendizado no desenvolvimento pagina web, é tambem serviu para eu escrever sobre cinema que uma das minhas paixões.

Escolhi a área de Sistemas de Informação pela oportunidade no mercado de trabalho por meio da computação, sendo umas das áreas mais promissoras no cenario atual de mercasdo, tendo varias oportunidades de carreria a se seguir. Considero a programação web e cybersegurança como áreas interessantes para meu desenvolvimento profissional e pessoal.
